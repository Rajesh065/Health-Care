**MedFlow Health** is an enterprise-grade, full-stack Healthcare ERP, Electronic Health Record (EHR/EMR), Telehealth Consultation, Pharmacy, Laboratory, and AI Clinical Triage System.

---

## 🌟 Modules & Features
1. **🧑‍⚕️ Patient Charts & EHR**: Demographics, historical vitals tracking, allergies, and chronic conditions.
2. **📝 SOAP Notes Engine**: Subjective, Objective, Assessment, Plan documentation with ICD-10 diagnostic coding.
3. **📹 Telehealth Video Consultation**: Virtual consultation suite with encrypted video/audio controls and live clinical notes.
4. **💊 Pharmacy & Inventory**: Prescription queue, automated stock deduction, and medication catalog.
5. **🔬 Laboratory & Diagnostics**: Test order lifecycle, specimen tracking, and abnormal value detection.
6. **💳 Billing & Claims**: Itemized CPT code billing and insurance claims adjudication.
7. **🏥 Hospital Operations**: Live ward & ICU bed occupancy telemetry and staff shift roster.
8. **🤖 AI Clinical Triage**: Algorithmic triage risk engine with urgency color categories (Green, Yellow, Orange, Red).
9. **🔒 HIPAA Compliance**: Role-based access control (RBAC) and immutable access audit logs.

---

## 🚀 Quick Start
```bash
# Install dependencies
npm install

# Start Backend (http://localhost:5000)
npm run dev:backend

# Start Frontend (http://localhost:3000)
npm run dev:frontend

# Run Tests
npm test
```
